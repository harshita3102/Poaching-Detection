🐾 Poaching Detection System using Computer Vision

📌 Project Overview
Poaching Detection is a computer vision–based system designed to help detect illegal poaching activities using video footage. The system analyzes live or recorded video streams and identifies suspicious human presence in restricted wildlife areas.

This project aims to support wildlife conservation efforts by enabling early detection and monitoring through automated video analysis.


 🎯 Key Features
- Detects human presence in wildlife surveillance videos
- Works on live and recorded video footage
- Uses deep learning–based object detection
- Generates detection results and outputs
- Modular and extensible Python codebase



 🛠️ Tech Stack
- **Programming Language:** Python  
- **Computer Vision:** OpenCV  
- **Deep Learning / ML:** YOLO / custom trained model  
- **Model Storage:** Pickle (`.pkl`)  
- **Video Processing:** MP4 video streams  
- **Environment:** Virtual Environment (`venv`)
